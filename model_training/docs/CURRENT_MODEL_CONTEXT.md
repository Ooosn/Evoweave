## 研究问题

从多姿态表面观测恢复完整骨架，并提高未见拓扑上的结构、位置和生成终止质量。
**真实帧之间的运动信息有收益是已确认的项目结论，不再重复验证。**
当前问题是在保留真实帧时序交互的基础上，全帧输出监督是否优于随机单帧监督。

## 当前任务

用户已授权先做单帧解码监督对照：无虚拟模块，保留相同多帧输入，只随机选择
一个真实帧进入 decoder。与已有无虚拟、全帧监督的 20k 结果比较，不重跑对照组。
新组从相同官方初始状态训练，停在 20k；100k 学习率周期保持不变。
本地 89 项 CPU 测试通过，实际 CPU 初始化与选帧检查、GPU 容量检查尚待验收；
正式训练尚未放行。此阶段不引入参考骨架定位架构，也不继续显式 ID 路线。
详见[单帧监督协议](SINGLE_QUERY_SUPERVISION_20261026.md)。

## 方法与数据

- 原始方法：真实 query 对齐的 1,024 anchor tokens，经空间/时间编码后，
  条件化完整 UniRig 自回归骨架序列；每次资产访问只监督 query 帧。query 是
  真实输入帧之一，老模型没有额外的虚拟 query 帧。
- A/B/C 的关键架构变化是新增一个无真实输入网格的虚拟 query 帧，含 1,024
  slots，再比较虚拟帧与真实帧的融合方式。三组都有虚拟帧；B 使用真实帧作
  attention query、虚拟帧作 key/value，仍属于新架构。多目标监督是另一项变化。
- 当前完整数据：18,002 训练 / 967 验证资产。固定 5k 是其中的实验子集，
  不是另一个数据版本；清单 SHA-256 为
  `a17b6be96fb33a32a1bee7117b07789da6261c6b5693104f3d2cce07c09bab88`。
- 预处理：完整读取 manifest 的 `root_rt`，去除根刚性运动，保留非刚性残差；
  在实际选中输入网格的联合 bbox 上统一中心与尺度，padding 为 1.1。
- 历史七月及十月十日训练使用 15,920 / 856 旧清单，和当前数据分开解释。

## 已形成的研究判断

1. 真实帧运动信息的收益已确认，不再重复做其有无对照；模型确实使用几何和姿态条件。
2. 高频骨架族的成功不能代表长尾泛化；关节数、拓扑频率和姿态需分开分析。
3. flat UniRig 的部分生成会在错误前缀下进入重复循环；强行结束不改善骨架本身。
4. 结构和坐标拆开预测具有可训练性，但现有证据尚未证明它提高了最终质量上限。
5. 后续比较需要固定资产、原始帧、GT、失败计分和曝光预算，再解释架构差异。
