## Model And Objective

One shared backbone encode produces1024 corresponding real mesh-anchor tokens
per pose. Both losses use this same differentiable computation. The existing
AR readout retains its deterministic random20%-40%, minimum2pose supervision.

The flow branch uses width256,8heads,2reference-conditioning blocks and6flow
blocks. Reference XYZ, parent offsets, root indicator, graph relations and
graph-hop bias identify joints without a semantic joint-ID vocabulary.
Corresponding reference/target anchor features, XYZ, normals and displacement
condition every flow block. Each block has graph attention, mesh cross
attention, unordered pose-set attention and an FFN. No video-index positional
encoding is added. A soft reference-distance prior only initializes reference
joint features; it does not constrain generated joints to the surface.

For each asset visit, independently choose one complete GT reference pose,
one uniform generative time tau, and standard Gaussian XYZ noise. All target
poses share tau; their XYZ noise is independent. Train the velocity on the
linear path x_tau=(1-tau)*noise+tau*GT with target velocity GT-noise. Average
squared XYZ error over coordinates, valid joints and non-reference poses,
then equally over assets. The reference coordinates are clamped exactly and
excluded from loss and scoring. Padding is masked throughout. Tau is not
animation time. Generation starts from seeded noise and uses32Euler steps,
with no target GT argument, fitted baseline, or best-of-N selection.

Total loss is AR cross-entropy plus lambda times flow velocity MSE. Lambda
ramps linearly to1over the first1000new asset visits. Equal numeric weights
do not mean equal gradient scales; the capacity record measures both the
combined objective and flow-only signals to the shared surface/motion encoder.
The flow-only loss must not traverse the AR decoder.

reference evaluation uses the fixed128validation panel initially and after

distance metrics explicitly report successful coverage. Do not assume their

Both reference conditions include unchanged-reference-copy controls with the
same meshes, reference slots and scoring. Final diagnostics separately cover
32training assets on seen and heldout raw poses. Normalized MPJPE divides
joint Euclidean distance by each target mesh's bounding-box diagonal. PCK@5%
counts joints within5%of that diagonal. Aggregate poses/references per asset,
then average assets. Score one seeded sample per reference, never GT-select it.

Training loss is not generation quality. A first-stage before/after change is

in this first trial. Likewise this does not settle shared versus independent
